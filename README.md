# DLW26 · Deep Learning Week 2026

Team development workspace for Deep Learning Week 2026, with backend risk and routing code and folders reserved for frontend and ML work.

## Repository guide

| Path | Contents |
| --- | --- |
| [backend/](backend/) | Server, risk scoring, routing, and graph data |
| [frontend/](frontend/) | Frontend placeholder |
| [ml-service/](ml-service/) | ML service placeholder |
| [schema](schema) | Shared schema file |

## Runnable demo

For the end-to-end SafeFlow demo and setup instructions, see [dlw26-safeflow-demo](https://github.com/i-singhal/dlw26-safeflow-demo).

## Team workflow

Work on a branch for your component, such as backend, frontend, or ML, and open a pull request into `main`. Do not push directly to `main`.
